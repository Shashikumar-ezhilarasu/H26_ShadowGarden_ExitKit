# ExitKit (H26_ShadowGarden_ExitKit)

> **Don't trust the AI's migration plan. Trust the receipt.**

ExitKit is an open-source Python CLI that dynamically analyses a target Python repository, detects at-risk dependencies, proposes replacements using Gemma 4, verifies them by executing code in an isolated sandbox, and emits a reproducible, reusable **Dependency Exit Capsule**.

---

## The Trust Ledger

ExitKit's core differentiator is the sacred **Trust Ledger**. Every claim in a capsule carries an explicit, tamper-evident trust level:

- `OBSERVED`: Grounded in real scan or sandbox execution data with matching SHA-256 evidence.
- `AI_PROPOSED`: Generated by Gemma 4 as a proposed migration or shim.
- `AI_PROPOSED_VERIFIED`: AI proposal validated and confirmed passing through sandbox differential testing.
- `AI_PROPOSED_REFUTED`: AI proposal failed sandbox verification or broke compatibility tests.
- `UNVERIFIED`: Statements that could not be evaluated by tools, flagged with a required note.

No claim can be marked `OBSERVED` unless its referenced evidence file exists on disk and its SHA-256 checksum matches.

For detailed transition rules and architectural invariants, see [Trust Ledger Documentation](docs/LEDGER.md).

## Supported Environments

- **Python Version**: `>=3.12, <3.14` (strictly tested on 3.12 and 3.13)
- **Package Manager**: [uv](https://github.com/astral-sh/uv)
- **Reasoning Engine**: Gemma 4 (bounded via `EXITKIT_GEMMA_MODEL`)
  - Backends: Google GenAI API, Ollama (and a tagged `mock` backend strictly for unit tests)

## Quickstart

### 1. Install & Setup with uv

```bash
# Clone the repository
git clone https://github.com/Shashikumar-ezhilarasu/H26_ShadowGarden_ExitKit.git
cd H26_ShadowGarden_ExitKit

# Sync dependencies
uv sync --all-extras
```

### 2. Configure Environment

Copy `.env.example` to `.env` and fill in your keys:

```bash
cp .env.example .env
```

Set your Gemma model identifier:
```bash
export EXITKIT_GEMMA_MODEL="gemma-4-it"
export GOOGLE_API_KEY="your-api-key"
```

### 3. Run Doctor

Verify your local installation and dependencies:

```bash
uv run exitkit doctor
```

Check the version:

```bash
uv run exitkit --version
```

### 4. Scan a Repository for Dependency Risks

Scan any local repository or remote git URL to discover all direct dependencies and compute evidence-backed risk scores:

```bash
# Scan a local repository
uv run exitkit scan ./path/to/target

# Scan and output JSON machine receipt
uv run exitkit scan ./path/to/target --json

# Run offline using cached payloads only
uv run exitkit scan ./path/to/target --offline
```

For the complete signal scoring breakdown, see [Risk Model Documentation](docs/RISK_MODEL.md).
